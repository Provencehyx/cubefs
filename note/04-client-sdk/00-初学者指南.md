# Client FUSE 五层解析 · 初学者指南

> 入口文件：[client/fuse.go](../../client/fuse.go) · [client/fs/](../../client/fs/)
> 核心问题：**CubeFS FUSE 客户端是怎么把 POSIX 文件系统操作转换成分布式存储访问的？**

---

## 1. 什么是 FUSE Client？

```
┌──────────────────────────────────────────────────────────────────┐
│                         用户态应用                                │
│              ls, cat, cp, rm, vim, gcc, ...                      │
└────────────────────────────┬─────────────────────────────────────┘
                             │ POSIX 系统调用
                             ▼
┌──────────────────────────────────────────────────────────────────┐
│                       Linux VFS                                   │
│                    (虚拟文件系统层)                                │
└────────────────────────────┬─────────────────────────────────────┘
                             │
                             ▼
┌──────────────────────────────────────────────────────────────────┐
│                    FUSE 内核模块                                  │
│                 /dev/fuse 字符设备                                │
└────────────────────────────┬─────────────────────────────────────┘
                             │ FUSE 协议 (用户态↔内核态)
                             ▼
┌──────────────────────────────────────────────────────────────────┐
│              ★ CubeFS FUSE Client (本项目)                        │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  bazil.org/fuse                                            │  │
│  │  (Go 语言 FUSE 库，处理 /dev/fuse 读写)                     │  │
│  └────────────────────────────────────────────────────────────┘  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  client/fs/                                                │  │
│  │  Super / Dir / File (实现 FUSE 接口)                        │  │
│  └────────────────────────────────────────────────────────────┘  │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  sdk/meta + sdk/data/stream                                │  │
│  │  (MetaWrapper + ExtentClient，访问集群)                     │  │
│  └────────────────────────────────────────────────────────────┘  │
└────────────────────────────┬─────────────────────────────────────┘
                             │ RPC
            ┌────────────────┴────────────────┐
            ▼                                 ▼
     ┌──────────────┐                  ┌──────────────┐
     │   MetaNode   │                  │   DataNode   │
     │  (元数据服务) │                  │  (数据服务)   │
     └──────────────┘                  └──────────────┘
```

**一句话**：FUSE Client 是一个运行在用户态的进程，接收内核发来的文件系统请求，翻译成对 MetaNode/DataNode 的 RPC 调用。

```
│  │  ec  *stream.ExtentClient   → DataNode (数据 RPC)       │    │

│  └─────────────────────────────────────────────────────────┘    │
│                                                                  │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │  缓存层                                                  │    │

│  │  dc        *Dcache          dentry 缓存                  │    │
│  │  nodeCache map[ino]Node     Dir/File 对象缓存            │    │
│  └─────────────────────────────────────────────────────────┘    │
│                                                                  │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │  孤儿列表                                                │    │

          │

```

## 4. 请求处理流程

### 4.1 读文件流程

```
用户: cat /mnt/cubefs/foo.txt
          │
          ▼
① open("/mnt/cubefs/foo.txt", O_RDONLY)
   → FUSE Lookup("foo.txt")
       → d.super.mw.Lookup_ll(parentIno, "foo.txt")
       → 返回 File 节点
   → FUSE Open(File)
       → f.super.ec.OpenStream(ino)
       → 返回 Handle
          │
          ▼
② read(fd, buf, 4096)
   → FUSE Read(offset=0, size=4096)
       → 热卷: f.super.ec.Read(ino, buf, offset, size)
       → 冷卷: f.fReader.Read(ctx, buf, offset, size)
       → 返回数据
          │
          ▼
③ close(fd)
   → FUSE Release()
       → f.super.ec.CloseStream(ino)
```

### 4.2 写文件流程

```
用户: echo "hello" > /mnt/cubefs/bar.txt
          │
          ▼
① open("/mnt/cubefs/bar.txt", O_WRONLY | O_CREAT | O_TRUNC)
   → FUSE Create("bar.txt")
       → d.super.mw.Create_ll(parentIno, "bar.txt", mode)
       → 返回新 File 节点
   → FUSE Open(File)
       → f.super.ec.OpenStream(ino, openForWrite=true)
          │
          ▼
② write(fd, "hello\n", 6)
   → FUSE Write(offset=0, data="hello\n")
       → 热卷: f.super.ec.Write(ino, offset, data)
       → 冷卷: f.fWriter.Write(ctx, offset, data)
          │
          ▼
③ close(fd)
   → FUSE Flush() (如果 fsyncOnClose)
       → f.super.ec.Flush(ino)
   → FUSE Release()
       → f.super.ec.CloseStream(ino)
```

## 5. 缓存层次

```
┌─────────────────────────────────────────────────────────────────┐
│  Level 1: Linux Page Cache (内核)                                │
│  - FUSE KeepCache 选项控制                                       │
│  - 文件内容缓存在内核内存                                         │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  Level 2: InodeCache (Client)                                    │
│  - ino → InodeInfo                                               │
│  - LRU + 过期驱逐                                                 │
│  - 减少 InodeGet RPC                                             │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  Level 3: DentryCache (Client)                                   │
│  - (parentIno, name) → childIno                                  │
│  - 减少 Lookup RPC                                               │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  Level 4: Extent Cache (ExtentClient)                            │
│  - ino → ExtentList                                              │
│  - 减少 GetExtents RPC                                           │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│  Level 5: Block Cache (可选)                                     │
│  - bcache 本地磁盘缓存                                            │
│  - 减少对 DataNode 的读取                                         │
└─────────────────────────────────────────────────────────────────┘
```

## 6. 热卷 vs 冷卷

| 维度 | 热卷 (Replica) | 冷卷 (BlobStore/EC) |
|------|----------------|---------------------|
| **存储后端** | DataNode (3 副本) | BlobStore (纠删码) |
| **适用场景** | 频繁读写 | 归档、冷数据 |
| **数据读取** | `ec.Read()` | `fReader.Read()` |
| **数据写入** | `ec.Write()` | `fWriter.Write()` |
| **truncate** | 支持 | 不支持 |
| **随机写** | 支持 | 只支持追加 |
| **后台 flush** | 不需要 | 每 2 秒检查空闲 writer |

## 8. 快速实验

### 8.1 编译客户端

```bash
cd cubefs
make client  # 生成 build/bin/cfs-client
```

### 8.2 挂载卷

```bash
./cfs-client -c /path/to/fuse.json
```

fuse.json 示例：
```json
{
  "masterAddr": "192.168.1.1:17010,192.168.1.2:17010,192.168.1.3:17010",
  "mountPoint": "/mnt/cubefs",
  "volName": "test_vol",
  "owner": "test",
  "logDir": "/var/log/cubefs",
  "logLevel": "info"
}
```

### 8.3 调试工具

```bash
# 查看挂载信息
mount | grep cubefs

# 查看客户端进程
ps aux | grep cfs-client

# 访问 pprof
curl http://127.0.0.1:17420/debug/pprof/

# 设置读写限速
curl http://127.0.0.1:17420/rate/set?read=100&write=100
```

## 9. 关键配置项速查

| 配置项 | 含义 | 默认值 |
|--------|------|--------|
| `mountPoint` | 挂载点路径 | 必填 |
| `volName` | 卷名 | 必填 |
| `masterAddr` | Master 地址列表 | 必填 |
| `owner` | 卷所有者 | 必填 |
| `icacheTimeout` | inode 缓存超时(秒) | 120 |
| `lookupValid` | lookup 结果有效期(秒) | 5 |
| `attrValid` | attr 结果有效期(秒) | 5 |
| `readRate` | 读限速 (MB/s) | 0 (不限) |
| `writeRate` | 写限速 (MB/s) | 0 (不限) |
| `enableBcache` | 启用块缓存 | false |
| `fsyncOnClose` | close 时 fsync | false |
| `keepCache` | FUSE KeepCache | false |
